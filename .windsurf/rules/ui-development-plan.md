# Windsurf Rules for UI Development Plan

## 1. Visual Style & Theme
- Adopt a modern, professional, clean, and uncluttered layout with ample white space.
- Focus interfaces on essential information; maintain clear visual hierarchy.
- Use user-friendly controls with clear affordances.
- Ensure consistent look and feel across all screens.

## 2. Color Palette
- Primary: #2563EB (Blue) – main actions, navigation, branding.
- Secondary: #10B981 (Green) – success states, secondary actions.
- Accent: #F59E0B (Amber) – highlights, warnings.
- Neutral: #6B7280 (Gray) – text, backgrounds, non-interactive.
- Error: #EF4444 (Red) – errors, critical alerts.
- Supporting: Background #F9FAFB, Surface #FFF, Border #E5E7EB, Text #111827/#4B5563.

## 3. Typography
- Use Inter font (sans-serif) for all text.
- Headings: H1-H5 (24px-14px, Bold/Semibold).
- Body: 16px/14px/12px (Regular).
- Buttons: 14px (Medium), Inputs: 16px, Table: 14px.
- Maintain clear distinction between headings, body, captions.

## 4. Brand Character
- Reliable: Consistent, stable UI.
- Efficient: Streamlined workflows, minimal steps for frequent tasks.
- Professional: Clean, organized information.
- Trustworthy: Clear status/data indicators.
- Modern: Use contemporary design patterns and interactions.

## 5. Screen Coverage
- Implement all required screens: Authentication, Dashboards (Admin/Branch/Operations/Finance/Driver), Master Data, Operations, Mobile Ops, Financial, Reporting, Settings/Admin.
- Each screen must have clear purpose, key elements, and user interactions as described in the plan.

## 6. UI/UX Patterns
- Use focused, minimal forms with validation, clear error/success states.
- Provide filtering, sorting, search, and drill-down for data-heavy screens.
- Use cards, tables, timelines, and maps for information display.
- Add sticky footers/headers for key actions.
- Use modals, sidebars, and overlays for secondary flows.
- Ensure all interactive elements are accessible and keyboard navigable.
- Support responsive design for desktop and mobile.

## 7. Workflow & Navigation
- Design workflows for minimal clicks and logical step-by-step progression.
- Use breadcrumbs, tabs, and navigation drawers for orientation.
- Provide quick access to frequent actions and dashboards.
- Maintain state and context across navigation.
- Use contextual help, tooltips, and clear error messages.

## 8. Accessibility & Consistency
- Adhere to WCAG 2.1 AA accessibility standards.
- Ensure color contrast, font legibility, and semantic HTML.
- Use consistent spacing, sizing, and component patterns.
- Test all screens for usability and accessibility.

## 9. Prototyping & Handoff
- Create interactive prototypes for all major flows.
- Provide annotated specs, assets, and usage guidelines for developers.
- Maintain up-to-date design documentation.

---
All UI development must follow these rules for consistency, usability, accessibility, and alignment with Samudra ERP's brand and business needs.
